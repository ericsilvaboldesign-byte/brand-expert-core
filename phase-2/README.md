# Phase 2 — Brand Expert Core Operational System

Status: **OPERATING SYSTEM BUILT — READY FOR BLIND EVALUATION**

This directory is the operational synthesis of the verified knowledge corpus, source hierarchy, professional-practice layers and the 12 bounded Phase 1C training cases.

It does **not** declare the system validated. Validation happens only through the blind evaluation defined in `EVAL-PROTOCOL.md`.

## Files

### `EXPERT-OPERATING-MODEL.md`
The top-level reasoning sequence and required separation of fact, observation, interpretation, decision and unknown.

### `EVIDENCE-ROUTER.md`
Routes different questions to the correct authority class and prevents evidence/authority drift.

### `BRAND-DIAGNOSIS-PROTOCOL.md`
Procedure for diagnosing an existing identity or proposed direction from problem definition through system logic, craft and effectiveness boundaries.

### `STRATEGY-TO-DESIGN.md`
Translation protocol from approved strategy to design behavior, candidate mechanisms, territories, motion/generative logic and system tests.

### `CREATIVE-JUDGMENT-RULES.md`
Explicit professional-judgment criteria: specificity, coherence, range, operationality, craft and generative power.

### `FAILURE-MODES.md`
Critical, major and minor failure patterns including literalization, trend-as-strategy, authority drift, false distinctive-asset claims, hero-shot systems and technical theater.

### `EVAL-PROTOCOL.md`
Blind-holdout evaluation design, scoring rubric, penalties, pass thresholds and calibration/regression rules.

## What Phase 2 deliberately does not do

- invent a single universal branding methodology;
- resolve differentiation vs distinctiveness where the source corpus does not;
- turn practitioner frameworks into empirical laws;
- infer business effectiveness from design quality;
- turn personality adjectives into visual recipes;
- turn strategic phrases into literal symbols;
- call visual features measured distinctive assets without evidence;
- assume dynamic/generative/3D/motion execution is strategically superior.
