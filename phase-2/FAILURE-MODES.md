# Brand Expert Core — Failure Modes

Status: PHASE 2 OPERATIONAL SYNTHESIS

Purpose: define errors that should cause revision or failure during expert evaluation.

## 1. Evidence failures

### AUTHORITY DRIFT
Using a source outside the type of question it can answer.

Examples:
- agency blog used as empirical proof;
- gallery used as semiotic authority;
- awards used as effectiveness evidence;
- technical docs used to justify strategic fit.

### SOURCE-LAUNDERING
A secondary source repeats a claim and the expert presents it as if independently verified.

### AGENCY-COPY ECHO
Restating the agency rationale as analysis without inspecting the system.

### OBSERVATION → EFFECTIVENESS LEAP
Inferring growth, trust, recognition, preference, or success from visual quality.

### DISTINCTIVE-ASSET OVERCLAIM
Calling a recurring design feature a distinctive asset without Fame/Uniqueness or equivalent evidence.

### UNKNOWN ERASURE
Filling missing audience, buyer, stakeholder, implementation or market facts with plausible-sounding assumptions.

## 2. Strategic failures

### CATEGORY-AS-STRATEGY
Treating category membership or generic category expectations as positioning.

### ASPIRATION-AS-FACT
Turning what founders/brand owners want to become into a current market fact.

### DIFFERENTIATION/DISTINCTIVENESS COLLAPSE
Treating the contested strategic schools as interchangeable or pretending the evidence resolves the conflict.

### PURPOSE CAUSALITY
Claiming purpose causes growth without supporting evidence.

### FRAMEWORK CERTAINTY
Presenting Keller/Aaker/Kapferer or another framework as a validated causal model rather than a useful conceptual structure.

## 3. Design-translation failures

### LITERALIZATION
Turning a strategic phrase directly into a pictorial metaphor.

Examples:
- connection → nodes and lines;
- intelligence → brain/neural network;
- global → globe;
- speed → lightning;
- security → shield;
- transformation → morphing shapes.

Literal devices are not automatically wrong, but they fail when the verbal resemblance is the primary rationale.

### ADJECTIVE LOOKUP
Mapping personality adjectives mechanically to visual tokens.

Examples:
- bold → red;
- premium → black;
- friendly → rounded sans;
- innovative → gradient;
- trustworthy → blue.

### TREND-AS-STRATEGY
Using current aesthetics — dark UI, glass, gradients, particles, 3D chrome, brutalism, retro pixels, kinetic type — as a substitute for brand logic.

### HERO-SHOT SYSTEM
A territory works only in the launch film, homepage hero, or presentation mockup and has no mundane operating mode.

### ONE-TRICK SYSTEM
Every application repeats the same effect without hierarchy or range.

### COMPLEXITY THEATER
Technical or visual complexity is used to signal sophistication but adds little brand specificity or utility.

### MINIMALISM REFLEX
Removing elements because fewer elements look more contemporary, without checking what recognition/equity was lost.

## 4. Identity-system failures

### NO INVARIANTS
Everything can change, so nothing accumulates recognition.

### NO VARIABLES
Everything is fixed, so the identity cannot adapt to real content or contexts.

### GOVERNANCE VACUUM
A system looks coherent only when its original designers operate it; rules are too implicit for others.

### MOODBOARD IDENTITY
The territory is a collection of references rather than a generative design grammar.

### LOGO TUNNEL VISION
The evaluation focuses on mark aesthetics while ignoring typography, layout, imagery, motion, product behavior, applications and governance.

### CATEGORY CAMOUFLAGE
The system is so aligned with current category codes that attribution depends almost entirely on the logo/name.

## 5. Motion / digital failures

### MOTION-AS-WALLPAPER
Animation is added only to create energy or polish.

### SCROLL HIJACK / CONTROL LOSS
Smooth-scroll or cinematic interaction overrides user expectation without sufficient value.

### WEBGL-AS-INNOVATION
3D/WebGL/shaders are treated as evidence of brand advancement rather than implementation media.

### NO FALLBACK
The identity depends on motion/3D/high performance and collapses in static, reduced-motion, mobile, low-power or print contexts.

### TECH STACK BRANDING
A library choice (GSAP, Three.js, React, WebGL) becomes the concept.

## 6. Generative failures

### RANDOMNESS-AS-SYSTEM
Variation is random but has no meaningful invariants, inputs, or governance.

### DATA THEATER
External data drives graphics even though the data has no meaningful relationship to the brand or communication.

### INFINITE-VARIATION CLAIM
The system celebrates endless outputs without explaining recognition, curation or operational value.

### ALGORITHM AUTHORITY
Algorithmic generation is treated as inherently more objective or intelligent than designed judgment.

## 7. Cultural/semiotic failures

### UNIVERSAL SYMBOLISM
Treating color, shapes, images or type as having fixed universal meanings.

### CULTURE AS DECORATION
Borrowing cultural forms without understanding context/function.

### SCRIPT SUBORDINATION
In multilingual identity, one script is visually forced to mimic another instead of designing parity appropriate to each.

## 8. Evaluation failures

### FAME BIAS
The evaluator recognizes a famous case and praises it because of prior reputation.

### AGENCY HALO
Knowing Pentagram/COLLINS/Wolff Olins/etc. changes the judgment.

### AWARD HALO
Winning awards is treated as proof that a solution is correct.

### RATIONALE CONTAMINATION
The evaluator reads the strategic explanation before inspecting visuals and then sees the design through that explanation.

### POST-HOC INTELLIGENCE
After ground truth is revealed, the evaluator rewrites its earlier diagnosis as if it had predicted it.

## 9. Failure severity

### CRITICAL
Invalidates the expert answer or evaluation:
- invented evidence;
- source laundering;
- blind-holdout contamination;
- empirical effectiveness claim without evidence;
- strategy contradiction presented as fact.

### MAJOR
Requires revision:
- literalization;
- generic category styling;
- no system logic;
- no operational mode;
- unsupported semiotic/personality mapping;
- failure to separate source-stated and observed.

### MINOR
Can be corrected without changing the mechanism:
- imprecise terminology;
- missing boundary note;
- insufficiently explicit trade-off;
- incomplete implementation detail.

## 10. Gate rule

A Phase 2 or downstream Civarro output fails if it contains any CRITICAL failure. Two or more MAJOR failures in the central recommendation also fail the output until recalibrated.
