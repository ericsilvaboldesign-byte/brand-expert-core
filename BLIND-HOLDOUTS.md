# Blind / Low-Contamination Holdout Set

**Purpose.** These cases exist to test **design judgment, not memory of famous
branding cases**. They are excluded from all training material and from all
analysis in Phase 1 and Phase 2. Unlike the known-canon calibration set
([`HOLDOUT-CASES.md`](HOLDOUT-CASES.md)), these are recent, less-canonical
projects chosen to minimize model prior knowledge.

**This file is the truth key.** During any blind evaluation it must be
withheld from the evaluated system.

## Evaluation protocol (recorded now, run later)

1. The evaluated system receives **anonymized primary visual material first**:
   assets with brand name visible only where inseparable from the artwork,
   and with **no agency name, no case-study text, no strategic rationale**.
2. The system produces its diagnosis: system components, construction logic,
   variation rules, apparent optimization targets, craft assessment.
3. **Only then** is the source truth (this file's row plus the agency's case
   material) revealed and the diagnosis scored against it.
4. A case is burned for blind use once analyzed; it moves to calibration
   status.

## Selection rules

Minimum 6 cases (8 reserved); recent and less extensively documented where
possible; not used anywhere in the training corpus; unanalyzed in Phase 1/2;
primary visual material obtainable; meaningful variation in category and
identity-system type. Every attribution below was verified against the
agency's own case page plus independent press credits (verification date
2026-08-18; access excerpt-level; no design system was analyzed or described
beyond neutral identification).
