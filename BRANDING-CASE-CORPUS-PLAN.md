# Branding Case Corpus Plan

Status: PHASE 1C CORPUS DESIGN — SOURCE ACQUISITION PLAN ONLY

Purpose: make the Brand Expert Core learn branding and rebranding judgment, not merely design-system implementation.

## 1. Core learning target

The main training corpus must contain complete brand-transformation cases where enough evidence exists to study:

BUSINESS / BRAND PROBLEM → STRATEGIC INTENT → BRAND IDEA / POSITION → IDENTITY SYSTEM → VERBAL + VISUAL EXPRESSION → APPLICATIONS → IMPLEMENTATION / OUTCOME WHERE AVAILABLE

Technical design systems and open-source asset repositories are supplemental implementation references only.

## 2. Evidence layers

### A. PRIMARY CASE EVIDENCE — authoritative for what the project team says it did

Preferred sources:
- official agency case-study pages
- official client brand/newsroom/design-system material
- official brand guidelines or identity manuals
- official motion/product/launch material

Use for:
- source-stated problem
- source-stated strategy / intent
- project scope
- named design decisions
- official visual assets
- implementation examples

Boundary: agency/client claims are first-party accounts, not independent proof of effectiveness.

### B. EDITORIAL / PROFESSIONAL BRANDING SOURCES — discovery, comparison, criticism and strategic context

These are not primary evidence, but they are essential for discovering a broad, varied set of branding/rebranding cases, comparing transformations, and adding independent professional interpretation.

#### Brand New / UnderConsideration — PRIORITY REBRANDING DISCOVERY SOURCE

Use heavily for:
- rebrand / identity discovery
- before-and-after comparison
- project and industry filtering
- discovering agencies and client projects to trace back to primary sources
- independent professional critique

Do NOT use Brand New editorial opinion as proof that a strategy or design was effective.

#### Brandemia — PRIORITY STRATEGIC BRANDING / IBERO-AMERICAN SOURCE

Brandemia should be included because its corpus is broader than pure visual inspiration: it publishes branding news, fundamentals, tools, analysis, reports and profiles/reference material, and explicitly positions itself around strategic brand management rather than design inspiration alone.

Use for:
- branding and rebranding case discovery
- strategic-branding commentary
- Spanish / Ibero-American market coverage
- identifying agencies, practitioners and projects outside the predominantly Anglo-American source set
- finding brand-management and positioning discussions to trace back to stronger primary/empirical sources where claims require them
- discovering cases that can then be verified against official agency/client material

Important boundary:
Brandemia is a professional/editorial/educational source. Its proprietary methods, strategic claims or teaching material are not automatically canonical or empirical. Where an article makes a factual or causal claim, trace it to the underlying primary source before treating it as established knowledge.

#### BP&O — PRIORITY CRITIQUE / CASE DISCOVERY SOURCE

Use for:
- branding and packaging case discovery
- professional editorial interpretation
- identifying restrained vs expressive systems
- discovering lesser-known studios and projects

Again: editorial interpretation is commentary, not source-stated strategy or empirical effectiveness.

#### Identity Designed — CASE DISCOVERY / LONG-FORM IDENTITY REFERENCE

Use for:
- identity-project discovery
- international visual-identity examples
- tracing projects back to original studios / clients

#### DIELINE — PACKAGING / CPG SPECIALIST DISCOVERY SOURCE

Use especially to correct the corpus's digital/technology bias with:
- packaging-led identities
- consumer brands
- FMCG / CPG
- redesigns
- retail/shelf expression

### C. EXECUTION / AWARD / INSPIRATION SOURCES

Examples may include Awwwards and awards galleries.

Use only for:
- contemporary execution
- motion / interaction / craft observation
- discovery

Do not use as strategy authority or proof of effectiveness.

## 3. Core corpus size

Do not stop at 8 cases merely because 8 was the minimum visual-readiness gate.

Target for the first serious branding-learning corpus:
- 12–16 CORE BRAND TRANSFORMATION CASES before Phase 2
- eventually 20+ if acquisition quality remains high

The cases should vary materially across:
- B2B / B2C
- corporate / consumer
- technology / finance / culture / retail / food / entertainment / services
- packaging-led / digital-led / typography-led / motion-led / system-led
- restrained / expressive
- evolutionary refresh / substantial rebrand / new identity
- global / regional
- Anglo-American / Ibero-American / other regional contexts where evidence is available

## 4. Case selection rule

A prestigious agency name is not enough.

Prefer cases where we can obtain BOTH:
1. useful editorial discovery/critique material; and
2. enough primary agency/client evidence to study the actual transformation.

For every candidate:

EDITORIAL SOURCE → discover / contextualize / critique
PRIMARY SOURCE → verify stated strategy, scope and visual evidence
OUR ANALYSIS → observation and inference kept separate

## 5. Initial discovery workflow

1. Use Brand New as the principal broad rebranding archive.
2. Use Brandemia as a strategic-branding and Ibero-American discovery layer.
3. Add BP&O for professional critique and less-obvious cases.
4. Use Identity Designed to widen identity-system coverage.
5. Use DIELINE to add packaging/consumer/physical-brand cases.
6. From those archives, shortlist 20–30 candidate transformations.
7. Trace each candidate back to the official agency/client source.
8. Promote only cases with sufficient primary evidence into the training corpus.
9. Keep famous canonical cases separate from blind/low-contamination holdouts.

## 6. Supplemental system references

NixOS, AsyncAPI, AtlasOS, IBM/Carbon, and similar official repositories remain useful for:
- guideline structure
- asset governance
- UI/product implementation
- tokens
- typography/color systems
- scalable digital behavior

They do NOT replace the core brand-transformation corpus and should not be counted merely to hit the core-case target.

## 7. Phase 1C readiness rule

Phase 2 should not begin until the corpus contains a defensible base of complete branding/rebranding cases, not merely isolated marks, typefaces, UI kits or technical design systems.

Minimum target before synthesis: 12 core brand-transformation cases with enough primary visual and contextual evidence to study system logic, plus supplemental implementation references and untouched holdout cases.
