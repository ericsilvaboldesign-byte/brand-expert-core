"Civarro Item 11" per `PHASE-1C-READINESS-REPORT.md`). Everything here is
**internal working material**, not public content and not approved copy.

Documents in this directory follow the corpus's evidence discipline: stated
access level, provenance, verbatim anchoring, and an explicit boundary
between what a source *says* and what is *verified* — see
`CASE-EVIDENCE-STANDARD.md` and `phase-2/EVIDENCE-ROUTER.md`.
